# Musik latar

- `tema.ogg` (asal: "397__Misc_Extras__bgm_space_upbeat_F") dipakai sebagai musik latar.

Nama file asli cocok dengan paket "400 Indie Game Music Loops" oleh Subspace Audio
(https://subspaceaudio.itch.io/indie-game-music-loops), yang dirilis CC0 di OpenGameArt.
Dikonversi ke Ogg Vorbis 96 kbps supaya ringan. Pastikan sumber dan lisensi file
yang kamu unduh sesuai sebelum game dibagikan luas.
